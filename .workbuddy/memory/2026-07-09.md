## 手机访问 dev server（网络层问题，非代码）
- 用户想用手机访问 Vue 网页。Vite 配置本来就支持：`user/vite.config.js` 已 `host: true`（端口 5174），`admin/vite.config.js` 已 `host:'0.0.0.0'`（端口 5173）。
- 实测：本机只有有线网卡 IP `10.94.155.36` 有效，无 192.168 类 WiFi 地址；172.x 是 Docker/WSL 虚拟网卡，169.254 是链路本地，均不可用。
- 实测铁证：netstat 显示 Vite 监听 `0.0.0.0:5174`（全网卡）；`curl localhost:5174`→200 OK，但 `curl 10.94.155.36:5174`→超时(exit 28)。「本机回环通、自身网卡 IP 不通」= **Windows Defender 防火墙默认开着且 10.94 被识别为公用网络拦入站**（回环 127.0.0.1 豁免故 localhost 能通）。即根因就是防火墙，不是用户以为的「没用过防火墙」，也非后端/代码。
- 修复：需管理员权限 `New-NetFirewallRule -Direction Inbound -LocalPort 5174 -Protocol TCP -Action Allow`（5173 同法）。Chat 里的 shell 非管理员，规则加不上，要用户在管理员 PowerShell 跑。
- 补充：即便放开防火墙，若手机与电脑不在同一子网（手机 WiFi vs 电脑有线 10.94 常被划不同 VLAN / 开 AP 隔离），手机仍路由不到 10.94；此时用「手机开热点 → 电脑连热点」让两边同网必通（仍可能需要上面的防火墙规则）。
